# WeChinaSourcing Visual Brand Identity

Official brand identity guidelines, visual assets, and design resources for **WeChinaSourcing**.

---

## 📁 Repository Overview

| File / Directory | Description |
| :--- | :--- |
| **`WeChinaSourcing-Brand-Guidelines.pdf`** | Complete official Brand Guidelines document (printable vector PDF). |
| **`WeChinaSourcing-Brand-Guidelines.html`** | Interactive web-based Brand Guidelines deck. |
| **`Quick-Start-Sheet.pdf`** | 1-page quick reference sheet for core rules, colors, fonts, and misuse dos & don'ts. |
| **`Quick-Start-Sheet.html`** | Web version of the quick start reference sheet. |
| **`STAGE1-PLAN-AND-KITTL-PROMPTS.md`** | Comprehensive audit, asset manifest, and image prompt specifications. |
| **`brand-assets/`** | Logos, tokens, icons, and vector elements. |
| **`Images/`** | Processed photography, application mockups, and approved brand photography. |
| **`inspiration images/`** | Visual moodboard and reference styling images. |
| **`source/`** | Raw editable source files and generation scripts. |

---

## 🎨 Core Brand Palette

- **Deep Navy**: `#0A192F` / Primary Brand Tone
- **Teal / Cyan**: `#00D2B4` / Primary Accent
- **Porcelain White**: `#FEFEFE` / Clean Background Canvas
- **Slate Gray**: `#64748B` / Secondary Supporting Neutral

---

## 🚀 Quick Usage Instructions

1. **Brand Guidelines**: Review `WeChinaSourcing-Brand-Guidelines.pdf` before creating marketing materials or UI layouts.
2. **Logos & Vector Assets**: Locate approved lockups in `brand-assets/`.
3. **Cheat Sheet**: Use `Quick-Start-Sheet.pdf` for immediate reference on color codes and logo clear space.
